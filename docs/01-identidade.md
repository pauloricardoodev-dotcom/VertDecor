# Identidade e direção criativa

**Marca:** VERT DECOR (wordmark elegante). **Conceito:** Organic Luxury — materiais naturais + design contemporâneo + sofisticação.
Transmitir: sofisticação sem exagero, exclusividade, elegância contemporânea, valorização dos materiais naturais, personalidade, atemporalidade.
Meta de reação do visitante: *"Uau. Que marca bonita. Quero conhecer essas peças."*

## Paleta (tokens)
| Token | Hex | Uso |
|---|---|---|
| `--forest` | `#173B32` | Identidade, profundidade, fundo do Manifesto |
| `--stone-green` | `#283F37` | Variação de verde, textos escuros |
| `--sand` | `#E9E2D5` | Predominante |
| `--offwhite` | `#F7F5EF` | Predominante (fundo base) |
| `--champagne` | `#B39A70` | **Muito moderado** — detalhes, indicadores |

Off-white e areia predominam; verde = destaque. Checar contraste AA (champagne sobre off-white provavelmente **não** passa para texto — usar só em elementos decorativos ou texto grande, validar).

## Tipografia
- **Cormorant Garamond** — títulos, chamadas, textos editoriais.
- **DM Sans** — navegação, descrições, botões, informações.
- Presença, hierarquia clara, muito respiro. Carregar via `@fontsource` (self-host, `display: swap`, só os pesos usados).

## Direção visual
Quero: fotografias grandes, composições assimétricas, espaço negativo generoso, elementos gráficos discretos, texturas naturais, contraste pedra/madeira/tecido/metal, transições suaves, animações refinadas.

Evitar: cara de template, layout de e-commerce genérico, cards em excesso, bordas em tudo, gradientes coloridos sem propósito, botões muito arredondados, animações infantis/chamativas, excesso de informação na primeira dobra.
